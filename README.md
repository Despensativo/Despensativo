### 🚀 Projetos em Destaque

- 🌐 **[OpenWrt-Skills](https://github.com/Despensativo/OpenWrt-Skills)**: Suíte definitiva de Agentic AI Skills (Google Antigravity, Cursor, Claude Code) para desenvolvimento em OpenWrt, LuCI, POSIX shell e networking de baixo nível.
- 📡 **[ark-router](https://github.com/Despensativo/ark-router)**: Painel LuCI/OpenWrt para Multi-WAN, Starlink/links móveis, mitigação de bufferbloat com SQM/CAKE e bonding Speedify.
- ⚡ **[Acer Predator Connect T7 Wi-Fi 7](https://github.com/Despensativo/Acer-Predator-Connect-T7-Wi-Fi-7)**: Guia completo, engenharia reversa e scripts para desbloqueio Root (SSH/Telnet), AP 2.5Gbps e Wi-Fi 7 MLO (Qualcomm IPQ5332).
- 📱 **[ipados-file-unlocker](https://github.com/Despensativo/ipados-file-unlocker)**: Solução via a-Shell para reparar arquivos bloqueados e erro `OSStatus -45` no app Arquivos do iOS/iPadOS sem perda de dados.

### 🛠️ Áreas de Interesse & Tecnologias

- **Redes & Firmware Embarcado:** OpenWrt, LuCI, BusyBox ash / POSIX Shell, `nftables` / `iptables`, SQM CAKE, Multi-WAN (`mwan3`), Wi-Fi 7 (MLO).
- **IA Agêntica & Automação:** Engenharia de prompts e skills para IAs de código (Antigravity, Cursor, Claude Code), automação de diagnósticos de firmware.
